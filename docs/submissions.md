# Submissions

Source: Junction platform (Project Submission page, Your Submissions page, Participant Guidebook). Event: Junction 2026, Hype Arena, Espoo.

## How many submissions

- **One project per team**, created by one team member. Team size is 1-4.
- That one project picks **one main challenge** (single "Challenge Picker" dropdown) and **any number of tech challenges** ("Tech Challenge Participation" multi-select).
- The Guide also says: "You are allowed to submit a project for multiple challenges." In practice this means one project entered in several challenges (the main one plus tech challenges), not several separate projects. The platform only exposes one project form.
- "Your Submissions" page lists the team's submissions. Currently: "You have no submissions yet."
- The project is editable any time before the deadline, even after setting it to Final.

Set the project to **FINAL** before the deadline. Draft projects are not reviewed.

## Form fields

Required (`*`): Project Name (max 30 chars), Punchline (max 200), Description (max 5000, markdown), Challenge (single pick).

Optional on the form: Project Demo link, Source Code link, Video link, Other link, Presentation upload (PDF, PPTX, PPT, ODP, KEY, max 20 MB), Tech Challenges (multi-select).

The Guide additionally lists for the final submission:
- Technologies used
- **2-minute video pitch**, public on YouTube/Vimeo etc. Strictly no longer than 2 minutes
- Demo and source code links, and whether the source code is public
- Whether you want to be credited for the project
- Pitch deck (PDF)
- Phone numbers of team members and a Discord username (for contact if you win)

Buttons: Save Draft, Submit Final (both disabled until all required fields are filled).

## Judging

- Challenge winners and runners-up are picked by each partner using their own criteria. Read the criteria of your challenge.
- Overall Top 5 come from **peer review**, then 7 judges vote. Criteria: Innovation, Impact, Implementation.
- If you or your team skip peer reviewing, you are **not eligible for the main prize** (10,000 EUR). Total prize pool is 100,000 EUR.

## Extra requirements from specific challenges

- **Cloudinary:** also fill the form https://cld.media/hackathon-survey
- **Nvidia Nemotron:** short text explanation in the submission form (model used, what it does, why it matters, how you improved outputs)
- **Context.dev / Oxylabs:** GitHub repo + demo + short note on which endpoints you used
- **Verda:** document your process and post a summary link in their Discord channel
- **Atech:** live demo on hardware, public repo or exported Atech project, ~2 min video
- **Aalto Humanoid:** Docker image with a policy server
- **IronShard:** large artifacts (over 100 MiB) go in an IronShard bucket, with references in the submission
